# Origin89 brand

The Origin89 identity as a package, `@origin89/brand`: the colour tokens for
both themes, the logos, the icons and the fonts, so that the website, the docs
site, Buddy and the app read the same files.

```js
import brand from "@origin89/brand";          // brand.json: names, colours, typography, file manifest
import "@origin89/brand/tokens/themes.css";   // every token as custom properties, both themes, switching wired
import "@origin89/brand/tokens/tailwind.css"; // the Tailwind @theme block (dark literals)
```

Files are addressed by their manifest path, `@origin89/brand/logos/origin89-horizontal-blue.svg`,
`@origin89/brand/fonts/InterTight-600.ttf`.

## Layout

- `palette/`: the colour values and the reasoning behind each one, and the contrast check every token must clear. The only place a colour is written.
- `logos/`, `icons/`, `fonts/`: the sources, shipped as they are. Fonts travel with their OFL files.
- `tokens/` and `brand.json`: generated by `build.mjs`, committed. `brand.json` lists every shipped file with its SHA-256; `verify.mjs` refuses a package whose files, manifest or generated outputs disagree with a fresh build.

Not here yet: the Buddy character and the editable Blender sources. They join
with a render pipeline that produces the sized images the products use, rather
than the studies and scene files behind them.

## Releases

Bump `version`, `npm run check`, commit, then push a tag `brand-v<version>`.
`publish-brand.yml` rebuilds, refuses a dirty diff and publishes through npm
trusted publishing with provenance. No token is stored in this repository.
